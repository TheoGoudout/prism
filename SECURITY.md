# Security Policy

## Supported versions

Only the latest version on the default branch is supported.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
(*Security → Report a vulnerability* on this repository). Include the steps
needed to reproduce the issue and the impact you expect.

You will get an acknowledgement as soon as possible. A fix will be released
before the issue is disclosed publicly.
